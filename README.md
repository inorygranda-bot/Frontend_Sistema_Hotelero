## Instalación y Puesta en Marcha

### 1. Clonar el repositorio y entrar al proyecto
```bash
git clone https://github.com/inorygranda-bot/Frontend_Sistema_Hotelero.git
cd Frontend_Sistema_Hotelero/frontend-hotel
```

### 2. Instalar dependencias
```bash
npm install
```

### 3. Configurar variables de entorno (Opcional)
Si usas un archivo `.env` para la URL de la API, créalo en la raíz de `frontend-hotel`:

```env
VITE_API_URL=http://localhost:5000
```

### 4. Iniciar el servidor de desarrollo
```bash
npm run dev
```

### 5. Abrir en el navegador
Abre la dirección que te genera la consola (por defecto):
```text
http://localhost:5173
```
